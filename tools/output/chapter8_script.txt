# 第8章「消えた配信者」脚本

## c8s01 / 深夜の依頼 / 橘 美羽

**ヤス:** 「こんな夜遅くに事務所を訪ねてくるとは…よっぽど急ぎの用件かい？」

**美羽:** 「すみません、でも警察は『成人の家出は事件性がないと動けない』って…。探偵さん、姉を探してください」

**ヤス:** 「お姉さん？詳しく聞かせてくれ」

**美羽:** 「姉は配信者なんです。『星野リコ』って名前で…3日前、ライブ配信中に突然画面が暗転して、それきり連絡が取れなくなりました」

**ヤス:** 「配信中に失踪…それは穏やかじゃないな。その時の配信映像は残ってるのか？」

**美羽:** 「はい、アーカイブをUSBに入れてきました。見てください…姉が最後に見せた表情、明らかに怯えてたんです」

## c8s02 / 途切れた配信 / 橘 美羽

**美羽:** 「姉のマンションはオートロックなのに、誰が来たんでしょう…」

**ヤス:** 「コメント欄が荒れてるな。『ざまあ』『消えろ』…これは？」

**美羽:** 「姉、最近アンチに粘着されてて…。匿名掲示板に専用スレッドまで立てられてたんです」

**美羽:** 「事務所との契約問題、熱狂的なファンからのストーカー行為、同僚との不仲…正直、心当たりがありすぎて」

## c8s03 / マネージャーの本音 / 神崎 蓮

**ヤス:** 「神崎蓮さんですね。橘莉子さんのマネージャーを？」

**ヤス:** 「失踪前、契約トラブルがあったと聞いたが」

**神崎:** 「…誰から聞きました？まあいいでしょう。彼女、独立したいと言い出したんです。今のタイミングで、ありえない」

**ヤス:** 「それで揉めた？」

**神崎:** 「ビジネスですから、多少の交渉はありますよ。でも僕が彼女を消すメリットがどこにあります？彼女は"商品"なんです、売れてる商品を壊す馬鹿がいますか」

## c8s04 / 冷たい計算 / 神崎 蓮

**神崎:** 「脅す？探偵さん、僕を何だと思ってます。彼女の配信を止めたら、僕の収入も止まるんですよ」

**ヤス:** 「失踪当日、あなたはどこに？」

**神崎:** 「別のタレントのイベント会場です。50人以上の目撃者がいます、アリバイは完璧です」

**ヤス:** 「莉子さんの住所を知っている人間は？」

## c8s05 / 推しへの執着 / 白石 ユウト

**ヤス:** 「失踪した日、彼女のマンションの近くにいたという目撃情報がある」

**ユウト:** 「…それは、たまたま近くを通っただけで…でも彼女には会ってません、本当です！」

## c8s06 / ガチ恋の闇 / 白石 ユウト

**ヤス:** 「それをストーカー行為と言うんだ」

**ユウト:** 「違う！僕は本気で心配してるんです！莉子さんは最近怯えてた、誰かに追い詰められてるみたいに。僕じゃない、別の誰かに…」

## c8s07 / 仲良しの仮面 / 瀬戸 カナ

**ヤス:** 「親友…ですか。でもあなたは彼女の人気を妬んでいたと聞きましたが」

**カナ:** 「誰がそんなこと言ったんですか？莉子は確かに人気者だけど、私は私のファンがいるから満足してますよ」

**ヤス:** 「匿名掲示板に莉子さんの誹謗中傷を書き込んでいた疑惑があるそうですね」

**カナ:** 「…それ、証拠あるんですか？」

## c8s08 / 嫉妬の証拠 / 瀬戸 カナ

**ヤス:** 「失踪当日は？」

**カナ:** 「自分の配信してました。アーカイブ見ればわかります。私がアリバイなしに見えます？」
